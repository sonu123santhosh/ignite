# SportLink (Ignite)

SportLink is a sports discovery and booking platform connecting athletes, facility owners, tournament organizers, coaching academies, and college teams.

## Platform Sections

- **Facilities & Grounds**: Turf discovery, slot booking, dynamic pricing, and venue management.
- **Tournaments**: Bracket view, fixture tables, team registration, results entry, and standings.
- **College Friendly Matches**: Team directory, match negotiations, challenges, and notifications.
- **Coaching Centres**: Coaching directory, coach credentials verification, trial bookings, and academy management.
- **Sports Trials**: Collegiate & club trials, candidate screening, document verification, scoring, and selections.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, React Router v7
- **Maps**: Leaflet & OpenStreetMap (`react-leaflet`)
- **Icons**: Lucide React
- **Persistence**: Safe browser storage wrapper & synchronized application contexts

## Running Locally

```bash
npm install
npm run dev
```

Build production bundle:
```bash
npm run build
```
